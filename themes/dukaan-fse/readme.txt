== Description ==
Urdu-first RTL WooCommerce shop theme for Pakistani bedding and
clothing sellers who take orders on WhatsApp with an advance-payment
model. Pakistani sellers ke liye: product page par Add to Cart ke
sath WhatsApp Order button — message mein product ka naam, qeemat
aur link pehle se likha hua.

== WhatsApp number (ek hi config jagah) ==
WordPress Admin → Settings → Dukaan → WhatsApp Number.
Digits only, country code ke sath (misalan 923001234567).
Number khali ho to WhatsApp button kahin nazar nahi ata.
Developers ke liye filter: dukaan_whatsapp_number.

== Requirements ==
Purple (the base) was built for WordPress 7.1+ and WooCommerce 11.1+.
This Dukaan test build targets WebDevHub's bundled stack
(WordPress 6.8.3 + WooCommerce 10.4) for evaluation — see the test
report for what that means in practice.
