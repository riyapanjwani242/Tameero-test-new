# Blueprints

Blueprint = ek click mein tayyar site. Shared bundle se dono platforms
par EK jaisi site banti hai.

## Business Site (`business`)
Home (front page) + About + Services + Contact, Primary menu,
plugins: Rank Math, Wordfence, UpdraftPlus, Elementor, GenerateBlocks,
Fluent Forms, FluentSMTP, W3 Total Cache, ASE.

## Online Store (`store`)
Business wala sab kuch + WooCommerce:
- Currency **PKR**, country Pakistan, COD gateway ON
- Woo pages: Shop, Cart, Checkout, My Account
- 3 sample products (Rs. 1,500 / 2,500 / 4,000)

## Blank (`blank`)
Koi blueprint nahi — sirf WP + pre-config (Urdu, Asia/Karachi, permalinks).
Plugins bhi activate nahi hote (plugins files mojood rehte hain).

Apna blueprint banana: `bundle/blueprints/<naam>/blueprint.json` —
`pages`, `menus`, `front_page`, `required_plugins` fields dekho.
